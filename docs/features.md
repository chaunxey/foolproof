# 功能细节

## 图片压缩

- 自研 `BitmapFactory` 采样 + `Bitmap.compress`，输出 JPEG / WebP，质量 0–100；
- 零权限：系统 Photo Picker 选图，写应用私有目录 + FileProvider；
- 批量串行，单张失败隔离；参数改动 300ms 防抖出预估体积；
- 支持**目标体积**：输入 KB 后自动降质量/缩尺寸，尽量不超过目标（签证/报名场景）；
- HEIC 仅 API ≥ 28 可解码；保存到相册仅 API ≥ 29；
- EXIF 方向纠正，重编码不保留定位。

## 重复照片清理

- 8×8 dHash + 汉明距离 ≤ 5 分组；低方差图额外保护；
- 每组默认勾选“除体积最大外”的副本，用户可改选，绝不自动删除；
- API ≥ 30 用 `MediaStore.createDeleteRequest`（回收站）；≤ 29 走 SAF 且不可恢复；
- 结果以重新查询 Uri 为准；仅申请读媒体权限，不申请写权限；
- 已知局限：水平镜像副本不会被识别（漏判，不是误判）。

## 视频压缩

- 档位：480p/720p/1080p × 高/中/低，H.264 + AAC 128k；
- 目标体积：自动 / 自定义 MB（上限 = 源文件大小）；按目标反推码率，超出自动降码率重试，最多 3 次；
- 裁剪双滑块，`ClippingConfiguration` + `Presentation` 一次转码完成；
- 结果对比、预览、进度轮询、取消清理；软编时如实提示；
- 输出 `files/videos/`，分享走 FileProvider，存相册走 MediaStore，不申请写权限。

## 视频裁剪

- 只保留时间轴选中的 `start–end`，不改分辨率/码率档位；
- Media3 开启 `trimOptimization`：关键帧对齐时尝试避免重编码，否则正常转码；
- 结果支持预览/分享/存相册，命名 `Foolproof_VID_TRIM_...`；
- 最小保留时长 0.5 秒。

## 视频拼接

- 2–10 段，逐段裁剪、拖拽排序、⋮ 菜单上移/删除；同一视频自动去重；
- 多段同时硬解在部分机型会失败：API 31+ 开启解码器回退，API < 31 走“逐段转码再拼接”的兼容路径；
- 每行按加入顺序分配颜色，拖拽时加阴影；
- 拼接结果支持预览/分享/存相册。

## 图片 / 文本 → PDF

- 图片多选（≤50）或拍照；A4 竖版、保持比例、EXIF 纠正、长边 ≤2048；
- 文本 ≤2MB，自研极简 Markdown，CJK 逐字折行；
- 原生 `PdfDocument` 生成；导出 `files/pdf/`，可存下载；
- 相机：CameraX 全屏拍照，前后摄/闪光灯，`PreviewView` 用 COMPATIBLE 模式避免 Dialog 黑屏。

## PDF 工具

基于 PDFBox-Android，全本地：

| 模式 | 行为 |
| --- | --- |
| 合并 | 多个 PDF 按列表顺序合并 |
| 拆分 | 页码范围（如 `1-3,5`）导出新 PDF |
| 旋转 | 整份文档 90°/180°/270° |
| 页面 | 页缩略图列表，左右移动/删除页，按新顺序重写 |
| 压缩 | PdfRenderer 栅格化 + JPEG 质量高/中/低，PDFBox 重建 |

- 压缩是**有损**的，文字层会变成图片；扫描件收益最大；
- 加密 PDF 目前直接失败，没有密码输入；
- 结果支持打开（系统阅读器）、分享、存下载、内嵌预览。

## 系统分享入口

- 其他 App 分享图片 → 自动切到图片 tab 并载入压缩；
- 分享视频 → 视频 tab，直接进入压缩；
- 分享 PDF → 转换 tab 的 PDF 工具；
- 多选图片/视频走 `ACTION_SEND_MULTIPLE`，复用原有批量流程。

## 已知限制

- 极短视频的实际体积可能比预估高 20%+（容器与 I 帧开销）；
- PDF 压缩不保留文本层；
- 页面缩略图逐页渲染，页数多时加载慢；
- 广告 placement ID 未配置时横幅为占位块，门控放行。
