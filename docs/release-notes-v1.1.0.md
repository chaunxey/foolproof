## Foolproof v1.1.0

### 图片
- 支持目标体积（KB）压缩，输出不超过设定上限；
- EXIF/位置信息开关，默认移除 GPS/设备元数据；
- 压缩完成弹层带首张预览，可分享/保存/关闭；
- 保存相册幂等：保存后按钮显示“已保存”，不会重复生成副本；
- 首页压缩结果行改为独立 lazy item，减少多图滚动掉帧。

### 重复照片
- dHash 距离 6–12 时增加灰度相关性兜底，压缩后的副本也能识别；
- 每组改为圆角卡片、组号/张数/可释放体积，相邻组边界清晰；
- 固定 3 列正方形，最后一行不足 3 张补空位，不再拉伸；
- 缩略图完整显示，不裁剪内容。

### 视频
- 视频 tab 支持压缩 / 拼接 / 裁剪三种模式；
- 左右滑动切换，顶部胶囊同步；
- 拼接支持 2–10 段、排序/删除/自动去重；
- 裁剪只保留 start–end，最小 0.5 秒；
- 压缩页保留左侧抽屉手势，拼接/裁剪页手势归 Pager。

### PDF 与转换
- PDF 工具：合并、拆分、旋转、页面管理、压缩、转图片；
- PDF 转图片支持预览、全部分享、保存下载；
- 分享 PDF 先复制到缓存，避免 Uri 授权过期导致失败。

### 系统分享
- 其他 App 分享图片 → 自动进入图片 tab 并开始压缩；
- 分享视频 → 视频压缩页；
- 分享 PDF → PDF 工具；
- 支持单选/多选。

### 登录与设置
- 本地模拟手机号验证码登录，30 秒倒计时；
- 独立密码登录页，无独立注册页；
- 左侧用户抽屉 + 全屏设置页，退出登录固定在底部；
- DataStore 统一存储登录态、语言、主题。

### UI
- 全页面内容左右 16dp；
- 底部导航选中态改为实心主题色 + 白色图标 + 加粗文字；
- 6 语言、深色模式、广告位保持兼容。

### 说明
- 登录为本地演示逻辑，不接后端、不发真实短信；
- PDF 压缩为有损，文字层会丢失；
- 未配置广告 placement ID 时横幅为占位块。
